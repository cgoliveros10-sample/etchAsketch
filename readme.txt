How to run
1. Keep all files in the same folder.
2. Open index.html in a browser, or use VS Code Live Server.

How to use
Move the mouse over the grid to draw. Each pass darkens a square by 10%.
New grid: enter squares per side (1-100).
Mode: switch between Black and Rainbow.
Clear: reset the canvas.
